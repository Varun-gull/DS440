# AI and Evaluation

Place the project’s data-science and AI work here.

Suggested organization:

```text
ai/
├── baseline/        Transparent keyword or TF-IDF matching
├── models/          AI matching and extraction implementations
├── prompts/         Versioned prompts and structured-output definitions
├── evaluation/      Metrics, labeled test sets, and error analysis
└── experiments/     Reproducible experiment configurations
```

The current keyword baseline and later AI system should remain separate so the team can compare them fairly on the same evaluation data.
