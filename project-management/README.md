# Project Management

This folder preserves the evidence needed for team coordination and DS 440 reporting.

- `meeting-notes/`: date, attendees, updates, blockers, decisions, and assigned next steps
- `sprint-reports/`: sprint goals, backlog, review, retrospective, and completed evidence
- `progress-reports/`: course progress-report drafts, figures, tables, and final submissions

Do not include private peer evaluations or sensitive student information in a public repository.
